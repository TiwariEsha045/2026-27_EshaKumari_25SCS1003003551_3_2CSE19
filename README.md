# Artificial Intelligence Internship – CodSoft

## 📌 About the Internship

This repository contains the projects completed during my **Artificial Intelligence Virtual Internship at CodSoft**, undertaken from **10 July 2026 to 10 August 2026**.

The internship focused on gaining practical experience in Artificial Intelligence concepts through hands-on Python projects.

## 🚀 Projects Completed

### 1. Rule-Based Chatbot

A simple Python chatbot that responds to predefined user queries using **pattern/keyword matching and dictionary-based logic**.

**Features:**

* Responds to greetings and basic questions
* Answers basic questions about Python and AI
* Displays the current date and time
* Supports a `bye` command to end the conversation

### 2. Tic-Tac-Toe AI

A console-based Tic-Tac-Toe game where the AI plays against a human using the **Minimax algorithm**.

**Features:**

* 3×3 game board
* Human vs AI gameplay
* Minimax-based optimal decision making
* AI is designed not to lose when playing correctly

### 3. Movie Recommendation System

A content-based movie recommendation system developed using the **MovieLens ml-latest-small dataset**.

**Technologies used:**

* Pandas
* Scikit-learn
* CountVectorizer
* Cosine Similarity

The system analyzes movie genres and recommends the **top 5 similar movies** based on genre similarity.

## 🛠️ Technologies & Tools

* **Programming Language:** Python 3
* **Libraries:** Pandas, Scikit-learn, datetime, math
* **Dataset:** MovieLens ml-latest-small
* **Development Environment:** Google Colab, Python IDE / Terminal
* **Version Control:** Git & GitHub
